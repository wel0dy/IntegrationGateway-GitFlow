# АИС «Интеграционный шлюз интернет-магазина»

Платформа синхронизации каталога товаров, складских остатков и платежных шлюзов.
Релизы выходят еженедельно, репозиторий ведется по модели **Git Flow**.

| Ветка | Назначение |
|---|---|
| `main` | только выпущенные версии с тегами `v1.x` |
| `develop` | интеграция готовых функций трех групп |
| `feature/*` | задачи групп: платежный модуль, складской учет, каталог |
| `release/v1.x` | стабилизация недельного релиза (четверг – пятница) |
| `hotfix/*` | срочные исправления выпущенной версии |
